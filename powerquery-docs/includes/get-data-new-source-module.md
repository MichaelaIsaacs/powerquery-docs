The **New** module provides a full list of connectors that you can select from. On this page, you can search for a connector across all categories by using the search bar at the top of the page. You can also navigate across the categories to find a specific connector to integrate with. When you select a connector, you open the connection settings window, which starts the [process of connecting](/power-query/get-data-experience#power-query-online-experience).
