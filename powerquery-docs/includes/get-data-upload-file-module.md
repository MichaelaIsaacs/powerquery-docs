The **Upload** module accepts file uploads directly through local file browsing or drag and drop. The following connectors support this capability:

- [Excel](/power-query/connectors/excel)
- [JSON](/power-query/connectors/json)
- [PDF](/power-query/connectors/pdf)
- [Text/CSV](/power-query/connectors/text-csv)
- [XML](/power-query/connectors/xml)

For more information about uploading files, see [Upload a file](/power-query/upload-file).
